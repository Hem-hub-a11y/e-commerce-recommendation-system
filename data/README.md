# Data Directory

This directory stores the datasets used by the E-Commerce Product Recommendation System.

## Datasets
- **`online_retail_II.xlsx`**: The raw transaction dataset (UCI Machine Learning Repository / Kaggle). Contains e-commerce transactions for a UK-based registered non-store online retail company between 01/12/2009 and 09/12/2011.
- **`online_retail_clean.parquet`**: Cleaned, validated, and normalized transaction records generated by `src/preprocessing.py`.
- **`product_catalog.parquet`**: Canonical mapping between `StockCode` and cleaned `Description`.

> **Note:** Raw and processed dataset files (`.xlsx`, `.csv`, `.parquet`) are excluded from version control via `.gitignore` to maintain clean repository hygiene.
